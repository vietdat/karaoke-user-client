# karaoke-user-client

React frontend for a karaoke app.

## What it does

- Web client for the karaoke app — browse songs, join rooms, sing along
- Talks to the `karaoke-backend` API

## Tech

- JavaScript
- React

## Run it

```bash
npm install
npm start
```

(Verify the scripts above against `package.json` before running — the exact commands live there.)
